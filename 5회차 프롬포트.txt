너는 이제부터 아주 창의적이고 유능한 웹 게임 개발자야. 아래 내용이 담긴 HTML 게임을 만들어보자.

[컨셉]
- 게임의 주제/내용 : (아기 공룡이 달콤한 디저트를 모으는 / 우주 비행사가 장애물을 피하며 지구로 돌아오는 / 꼬마 마법사가 몬스터를 물리치고 보물을 찾는 / 귀여운 고양이가 생선을 찾아 모험하는) 게임
- 게임의 분위기 : (아기자기하고 귀여운 / 스릴 넘치고 빠른 / 신비롭고 몽환적인 / 알록달록하고 신나는) 분위기
- 캐릭터 : 업로드하는 캐릭터 이미지를 주인공으로
- 배경 : 업로드하는 공간 이미지를 배경으로 참고해서 (비밀의 숲 속 / 반짝이는 은하수 / 달콤한 캔디 마을 / 깊은 바닷속 궁전)으로 생성

[필수 기능]
- 플레이어 조작 방법 : (키보드 화살표 방향키 / 마우스 클릭 및 드래그 / 스페이스바와 방향키 / 화면 터치)
- 장애물과 보상 : (뾰족한 가시와 운석 / 괴물 버섯과 떨어지는 바위 / 화난 몬스터와 불꽃) 을/를 (점프해서 / 좌우로 움직여 / 보호막을 써서) 피하고, (반짝이는 황금 별 / 달콤한 딸기 케이크 / 마법 보석) 을/를 획득할 수 있음, (장애물)에 닿으면 (하트 점수가 1개 깎임 / 캐릭터가 반짝이며 1초간 멈춤 / 점수가 50점 감점됨)
- 보상 획득시 변화 : (보상) 을/를 획득하면 (점수가 100점 오르고 효과음이 남 / 캐릭터 크기가 잠시 커짐 / 이동 속도가 빠르게 변함)
- 게임 종료 시점 : (보상 10개를 모두 수집하기 / 제한시간 60초 동안 살아남기 / 최종 목표 지점에 도착하기)
- 기타 기능 : 필살기 사용과 가능 조건, 점수 표시 바 등

[구현조건]
- 개발에 필요한 조건 : (HTML과 CSS, JavaScript를 한 파일에 작성 / 모바일과 PC 모두 플레이 가능한 / 2D 아케이드 스타일 / 코드마다 친절한 한글 주석 포함 / 횡스크롤 방식 설정)
