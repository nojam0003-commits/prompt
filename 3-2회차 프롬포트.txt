[역할부여]
너는 이제부터 아주 창의적이고 유능한 공간 디자이너야. 네가 만드는 공간은 아동·청소년들이 창작한 캐릭터가 살거나 활동하는 공간이 될 예정이야. 캐릭터와 어울리는 공간을 만들어야 해. 아까 내가 보낸 공간 사진들을 활용하고 아래 배경 설정 내용과 디자인 요청 사항을 반영해서 멋진 공간을 만들어줘.

[배경 설정]
- 공간의 느낌 : (신나고 활기찬 / 따뜻하고 포근한 / 신비롭고 차분한 / 화려하고 미래지향적인) 의 (알록달록한 무지개 / 따뜻한 주황과 노랑 / 시원한 미공간 파랑 / 신비로운 은색과 보라) 톤의 공간
- 공간의 형태 : 주로 (거대한 과자와 젤리 나무 / 반짝이는 수정과 유리 미끄럼틀 / 공중에 떠 있는 섬과 푹신한 구름 / 기계 톱니바퀴와 로봇 부품) 들로 이루어져 있으며, (알록달록한 미끄럼틀이 연결되어 있는 / 비눗방울이 끊임없이 떠다니는 / 중력이 없어서 물건들이 둥둥 떠다니는 / 빛에 따라 벽 색깔이 바뀌는) 특징이 있음

[디자인 요청] 
- 잔인하거나 유해한 요소는 절대 제외
- 실내/실외여도 되고, 비현실적인 공간을 추천
- 콜라주 기법을 사용
- 비율 : (세로형 / 가로형) 4:3비율
